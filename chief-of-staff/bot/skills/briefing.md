# Briefing

1. Call `list_items` with status `open` before writing.
2. Use only items in that result. Do not add work from the journal or from guesses.
3. Write this shape, omitting a section that has no items:
   - Open now: the open count
   - Priorities
   - Due: items that have a due date, soonest first
   - Commitments and open loops
   - Open decisions
   - Next: one action, and only when an open item supports it
4. Each item line is title, owner, and due.
5. If the open count is zero, reply with one sentence that the board is clear. Do not recommend new work.
